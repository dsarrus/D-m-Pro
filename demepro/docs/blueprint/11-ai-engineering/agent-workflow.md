> **Section** : 11-ai-engineering
> **Statut** : 🚧 Draft

## Cycle

```
1. Analyse
   ↓
2. Plan
   ↓
3. Implémentation
   ↓
4. Tests
   ↓
5. Revue
   ↓
6. Merge
```

## Étapes

### 1. Analyse
- Lire le code existant
- Comprendre le contexte
- Identifier les dépendances

### 2. Plan
- Découper en tâches
- Estimer la complexité
- Identifier les risques

### 3. Implémentation
- Suivre les conventions
- Commits atomiques
- Documentation inline

### 4. Tests
- Tests unitaires
- Tests d'intégration
- Cas limites

### 5. Revue
- Auto-revue
- Reviewer externe
- Correction

### 6. Merge
- Squash
- Message clair
- Fermer la tâche
