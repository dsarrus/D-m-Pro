## Versioning

**Semantic Versioning** : MAJOR.MINOR.PATCH

- **MAJOR** : breaking changes
- **MINOR** : nouvelles fonctionnalités
- **PATCH** : bug fixes

## Cadence

| Type | Fréquence |
|---|---|
| Patch | À la demande |
| Minor | Toutes les 2 semaines |
| Major | Trimestriel |

## Canaux

| Canal | Usage |
|---|---|
| alpha | Interne |
| beta | Early adopters |
| stable | Production |

## Rollback

En cas de problème critique, rollback immédiat vers la version précédente.
